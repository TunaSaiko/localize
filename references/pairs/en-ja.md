# 语对包：en → ja（英语 → 日语）

状态：**种子包**。和製英語/义变外来语来自维基清单；结构条目来自 Microsoft 日语指南、JTF、Knight 1995 的反向推论和模型知识；**未逐条核验出处**。

## 1. 本方向的捷径

**片假名转写。** 不去找日语既有说法，直接把英文词音译成片假名。看起来专业，实际是生造词，或者撞上一个日语里义项已经漂移的外来语。

## 3. 结构：英语有而日语没有的东西（反向处理）

Knight et al. 1995 列出日语缺少的：冠词、单复数标记、一致、主语常省略、无明确将来时。英→日时反过来：
- **you** → 省略，或 御社／お客様／ユーザー；不要「あなた」（UI 与商务文书里生硬）。
- **we** → 弊社／当社／私たち（按语体），常可省。
- 冠词、单复数：不译；「複数の」只在必要时加。
- **can** → 「〜できます」，不要「〜することができます」（冗长）。
- 祈使句（UI）：菜单/按钮 体言止め 或 常体；消息 です・ます（Microsoft 日语指南）。
- 修辞性疑问、感叹：日语商务文书少用，改陈述。
- 长句：英语一句可拆成日语两句；逻辑连接词（therefore, however）不必每个都译成 したがって／しかし。
- 「〜と思います」不要泛用于表达确定的陈述。

## 4. 字符与格式

- 长音：内閣告示原则加「ー」（コンピューター），惯用可省（コンピュータ）；**只判全文统一，不判错**。Microsoft 2008 年起加。
- 日英之间空格：JTF 不加 / Microsoft 加，项目开关。
- 数字半角、单位半角；全角英数字禁止；半角片假名禁止。
- 细则见 `locales/ja-JP.md`。

## 5. 长度

英→日**字符数收缩**（-10% 到 -55%），但**显示宽度膨胀**（"desktop" vs 「デスクトップ」）且行高更高。短串（按钮、标签）最先溢出。软件字符串禁用全角波线。

## 6. 语体默认

商务文书、公告、UI 消息 です・ます；技术规范 である；UI 菜单 体言止め。全篇一种。
