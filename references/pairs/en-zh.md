# 语对包：en → zh（英语 → 中文）

状态：**种子包**。来源：余光中《怎樣改進英式中文？》（1987）、维基百科「翻译腔」条目、CY/T 154—2017、GB/T 15834/15835、Microsoft zh-CN 指南 §2.1.4；结构条目按词类组织，**未逐条核验出处**。目标 locale 必须先定（zh-CN / zh-TW / zh-HK），见对应 locale 包。

## 1. 本方向的捷径

**词对词直译，句法结构原样保留。** 产出"翻译腔"：被动泛滥、"的"堆叠、"进行/作出"弱动词、"之一"、"们"、"性"、逻辑连接词每句都有。Microsoft zh-CN 指南 §2.1.4 标题就叫 "Word-to-word translation"。

## 2. 余光中的分类（按词类，不按词表）

来源：https://wiki.loikein.one/meta-life/quotes/yu-kwang-chung-against-engnese/ （非官方转载）。**核心观察：他的清单里几乎没有一条是"词义译错"，全部是结构层的廉价对应。** 所以英→中检查项按词类组织。

| 词类 | 症状 | 例 | 改 |
|---|---|---|---|
| 名词 | 抽象名词作主语 | 他的收入的减少改变了他的生活方式 | 他因收入减少而改变了生活方式 |
| 名词 | 弱动词 + 名词（作出/进行） | 对…作出了贡献／进行了讨论 | 贡献了／讨论了 |
| 名词 | 伪术语「〜性」「〜度」 | 可读性很高／知名度 | 好读／有名 |
| 名词 | 「们」滥用 | 观众们／读者们 | 观众／读者（中文名词不标复数） |
| 名词 | 「之一」滥用 | 最重要的原因之一 | 一个重要原因 |
| 连接词 | and → 和/以及/与 泛滥 | 男人和女人和孩子 | 男女老幼（用顿号或省） |
| 介词 | 有关/关于/由于/对于 | 关于这个问题的讨论 | 讨论这个问题 |
| 副词 | 「地」滥用 | 成功地完成了 | 完成了 |
| 形容词 | 「的」堆叠 | 一个美丽的安静的小的村庄 | 一个美丽安静的小村庄 |
| 动词 | 「被」滥用 | 他被选为主席 | 他当选主席 |

## 3. 其他高频翻译腔

- 「当…的时候」（when）→ 常可省"当"和"的时候"之一。
- 「作为…」（as）→ 常可省。
- 「对于…而言」「就…来说」→ 常可省。
- 「如此…以至于」（so…that）→ 改写。
- 「不仅…而且」→ 保留但不要每个 not only 都译。
- 「一个」（a/an）→ 中文常不需要量词冠词。
- 「它」「他们」（it/they）→ 中文靠省略指代，删。
- 「这」开头的句子（This shows…）→ 常改。
- 长句：英语一句拆中文两三句；定语从句后置改前置短定语或拆。
- 维基「翻译腔」条目给了 24 条症状和 3 条速判规则：https://zh.wikipedia.org/zh-hans/Wikipedia:翻译腔

## 4. 字符与格式（zh-CN，细则见 locale 包）

- 引号：GB/T 15834 横排用 “” ‘’ 外双内单；「」只用于竖排。zh-TW 反之用「」『』先单后双。
- 中英之间空格：CY/T 154 §8.1 **可选但须全库统一**；§8.2 **英文与中文标点之间不加空格（强制）**。「中文文案排版指北」是社区约定，不是国标。
- 数字范围：GB/T 15835 用「～」或「-」；**9亿~16亿 不写 9~16亿；15%~30% 不写 15~30%**。
- 省略号 ……（六点）；破折号 ——（两字长）。
- 百分号、单位与数字之间不加空格。
- 日期：2026年9月3日；货币：人民币／元／CNY，`¥` 在对外材料标明币种。

## 5. 数字换算

million→百万；billion→十亿；trillion→万亿。英文 1.2 billion → 12 亿（不要写"1.2 十亿"）。

## 6. 模型已知弱点

- "的"堆叠和"被"泛滥最常见。
- 逻辑连接词每句保留。
- 把 you 译成"你/您"不统一；技术文档默认"您"或省。
- 引号用「」而 locale 是 zh-CN。
