# 语对包：ja → zh（日语 → 中文）

状态：**种子包**。捷径与结构条目来自实战经验和模型知识，商务假朋友表为教材高频项，**未逐条核验出处**；用前按 T1/T2 动作验证。目标 locale 必须先定（zh-CN / zh-TW / zh-HK），见对应 locale 包。

## 1. 本方向的捷径

**汉字直搬 + 日语句法留痕。** 日语汉字词原样搬进中文，读者"看得懂"但义项不同；同时日语的长定语、被动、名词化、「〜的」「進行」「対応」被逐字带进来，产出日式中文。

## 3. 日式中文的结构留痕

| 日语结构 | 直搬（错） | 中文原生 |
|---|---|---|
| 〜の存在 | …的存在 | 直接说事物 |
| 〜性／〜化 泛滥 | 可能性／効率化 | 能不能／提高效率 |
| 〜を行う／〜を実施 | 进行…／实施… | 直接用动词 |
| 〜に対して | 对于…／针对… | 常可省 |
| 〜という | …这样的／所谓… | 常可省 |
| 〜として | 作为… | 常可省或改写 |
| 〜れる／られる（被动） | 被… | 中文少用被动，改主动 |
| 长定语前置（〜した〜） | …的…的… | 拆句 |
| 〜ことができる | 能够做到… | 能／可以 |
| 〜と思われる／〜と考えられる | 被认为… | 一般认为／我们认为，或直接陈述 |
| 敬语 お／ご／いただく／くださる | 承蒙您… | 一般不译；语体用"您" |
| 〜のほど／〜の程 | …的程度 | 省 |
| 〜については | 关于… | 常可省 |

## 4. 外来语 → 中文既有译名

不要音译片假名。ソリューション→解决方案；コンセンサス→共识；スキーム→方案／架构；リソース→资源；ノウハウ→专业知识／诀窍；コミット→承诺；アサイン→分配；エビデンス→证据／依据；フェーズ→阶段；マイルストーン→里程碑；ガバナンス→治理。

## 5. 数字与格式

- 億→亿、万→万；**兆→万亿**（不是"兆"）。
- 和暦（令和 N 年）→ 公历，必要时并记。
- 円→日元；「¥」在中文语境歧义（人民币也用 ¥），对外材料写"日元／JPY"。
- 「〜」区间→ 中文用「～」（U+FF5E）或「-」，按 locale 包。
- 姓名：日本人名保留汉字；片假名外国人名→中文通译名。

## 6. 模型已知弱点

- 保留日语敬语层级，产出"承蒙、敬请、恳请"堆叠。
- 长定语不拆句。
- 「対応」「検討」「案件」全篇一个译法（其实按语境要变）。
- 「〜と思われます」译成"被认为"，确定性被上调或下调都有。
