## 1. 本方向的捷径

**汉字词形对应。** 中文有个词，日语找个字形接近的汉字词。双方都"看得懂"，但语义、褒贬或用法不同。它不会触发你的警报，只会在母语者那里失败。

规律：语对之间存在一个"看起来能一一映射"的浅层（这里是汉字字形），真正的差异住在更深一层（义项、褒贬、能否作某种词性用）。**共享汉字越多，越危险。** 实证：懂中文的日语学习者在同形异义词上的表现显著差于完全不懂中文的英语母语者（加藤 2005）。

开工第一件事：把这一句抄进 `00-brief.md`。

## 4. 中文修饰结构 → 日语原生表达

来源：实战经验。**无规范出处**（日语权威文件全是表记规范，不涉及句法与母语干扰）。

| 中文结构 | 逐词译（错） | 日语原生 |
|---|---|---|
| 越…越… | （直接罗列） | 〜ほど〜 |
| 每次… | 一回一回の | 〜のたびに |
| …更锋利/更准 | 鋭くなる | 精度が上がる |
| …背景（履历） | バックグラウンド | 〜出身 |
| 外推 N 年 | N年を伸ばす | N年を試算／外挿 |
| 通过…实现… | 〜を通じて〜を実現 | 〜により〜（或直接动词） |
| 对…进行… | 〜に対して〜を行う | 直接动词（分析する、検討する） |
| 具有…性 | 〜性を持つ | 形容词或动词直接表达 |
| 一系列 | 一連の（可用） | 一連の／各種／複数の |
| 打造 | 作り上げる | 構築／整備／提供 |
| 赋能 | エンパワー（生造） | 支援／実現／可能にする |
| 落地 | 着地（错） | 実装／導入／実現 |
| 抓手 | （不存在） | 手段／切り口 |
| 沉淀 | 沈殿（错） | 蓄積／ノウハウ化 |

## 5. 字符陷阱（摘要）

细则和码位见 `locales/ja-JP.md`。最常踩的：
- 中黑「・」U+30FB，不是「·」U+00B7
- 区间「〜」U+301C，不是「～」U+FF5E；**软件字符串禁用全角波线**，改「から」或半角连字符
- 「~」在日语**不表示"大约"**；写「約」（惯用）或「余り」「数十」（公用文写法）
- 「+」后缀 →「以上」更清楚
- 长音符「ー」易被误写成「一」或「1」（OCR/输入法）
- 日英之间的半角空格：**JTF 不加 / Microsoft 加**，项目级开关，全篇统一
- 大数单位：日本受众读「億/兆」比 B/T 快一个数量级

## 6. 长度：字符数收缩、显示宽度膨胀

- 中→日：**字符数变多**（汉字词展开成假名、外来语变片假名），显示宽度也变大。表格单元格、卡片标题、图表标签、按钮最先溢出。
- 规律：源串越短，膨胀率越高。
- 版式约束有时给出更好的语言答案：放不进框时，第一反应是"我的表达是不是不够地道"，日语原生说法通常比直译短。
- 跑 `scripts/length_estimate.py`。

## 7. 本方向模型的已知弱点

- **非英语中心方向**：可解释性研究显示英语主导的模型在中间层用英语作枢轴，中↔日直译可能经过一次隐性的英语，产生"英语腔的日语"（冗长的主语、多余的代词、逻辑连接词泛滥）。⚠️ 来自论文摘要，未逐篇验证。
- 同形词负迁移：模型同样会被汉字字形带走。T1 默认怀疑。
- 敬体/常体混用、「〜することができます」「〜と思われます」等冗长句式泛滥。
- 生造片假名词（把中文行话音译成不存在的外来语）。

## 8. 同形词研究数据

汉日二字汉语词里，真正会咬人的"部分重合（O）+ 意义显著不同（D）"占 **3.5%–25%**（口径差异大）：文化庁 1978 约不到 1/10；陳 2002 O 13.3% + D 3.5%；許 2014 O 24.81% + D 7.18%；松下等 2020 约 2 成。
**实务含义**：D 型（手紙）一眼能看出，**O 型（部分重合，如 検討、深刻、迷惑）才是悄悄滑过去的**，优先盯 O 型。

## 9b. 商务/投资材料の"字面对但不是业界说法"（母语者实测）

**这一节的性质**：下面每条的日语译法**字面都不算错**，语法也通，
但**日本の同类材料不这么写**。这类词字典查得到、语对包的假朋友表抓不到——
**只有母语者读了才知道**。所以本节是**实测沉淀**，不是推导出来的。

**出处与强度**：某商业提案 zh→ja，多轮日本母语者盲测（投资材料语境）。
标 **3/3** 的是三人一致。表中的 SNF 指"不该误报的情形"（should-not-flag）。**未做语料库验证**，是"母语者一致证言"级别。
**换材料类型（消费品文案、技术文档）前先重新确认。**

| 中文 | 流程产出的（字面对） | 母语者的说法 | 一致度 | 为什么 |
|---|---|---|---|---|
| 已验证（实绩徽章） | `検証済み` | **`実績`** | **3/3** | 投资材料 traction 徽章的定番。`検証済み` 让人想到**第三方验证**，是过大表示 |
| 公司结构 | `会社形態` | **`会社概要`** | — | **假朋友**：`会社形態` ＝ 法人类别（株式会社/合同会社）。已进上面的假朋友表 |
| 已知事实（段头） | `既知の事実` | `ファクト` / `市場の現状` / `足元の市場動向` | 2/3 | "Known facts" 的直译感 |
| 疑问形の見出し | `当社は何をする会社か` | **体言止め**（`事業概要`） | 2/3 | 疑问句见出しは**採用ページ/社内資料のトーン**。投资材料は体言止め |
